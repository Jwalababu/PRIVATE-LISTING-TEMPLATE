This is SQL sample templace to create listings and sharing with external exxounts. It also has SQL commands to add and remove accounts.
Also there is  section on data consumer scripts to imprt the shares and start using the shares.

Before using: Replace all <ORG_NAME>, <ACCOUNT_NAME>, and <CLOUD_REGION> placeholders (e.g., PUBLIC.AWS_US_EAST_1), 
and update the manifest file path. Cross-region requires Cross-Cloud Auto-Fulfillment enabled on your account.
